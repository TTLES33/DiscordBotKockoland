# DiscordBotKockoland

DISCORD Bot - Kockoland

## Commands
```
--embed - Odesílání Embed(zvýrazněné) Zprávy
--stats - Statistiky serveru
--help  - Nápověda
```

## Reklama

Mazaní jakékoli zprávy obsahující ``` discord.gg/```
Odeslání oznámení o reklamě do roomky ttlesův-bot

## Script_commands

Pokud odeslaná zpráva obsahuje ``` =play``` ```=queue``` ```=skip``` ```=purge``` ```=rank``` a není v bot-příkazy upozorní odesilatele na špatný channel
