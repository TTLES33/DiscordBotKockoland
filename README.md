# DiscordBotKockoland

DISCORD Bot - Kockoland

## Commands
```
--embed - Odesílání Embed(zvýrazněné) Zprávy
--stats - Statistiky serveru
--help  - Nápověda
```

## Reklama

Mazaní jakékoli zprávy obsahující ``` discord.gg/```
Odeslání oznámení o reklamě do roomky ttlesův-bot

## Script_commands

Pokud odeslaná zpráva obsahuje ``` =play``` ```=queue``` ```=skip``` ```=purge``` ```=rank``` a není v bot-příkazy upozorní odesilatele na špatný channel

## Script_commands

Maže zprávy obsahující slovo z databáze.

* `--av` Zobrazí tuto nápovědu

* `--av list` List blokovaných slov a vyjímek

* `--av add` Přidá slovo do blacklistu

* `--av delete` Odebere slovo z blacklistu

* `--av exc add` Přidá slovo do vyjímek

* `--av exc delete` Odebere slovo z vyjímek
